What C++ says vs what the machine does
The standard talks about……which on Linux usually means
automatic storage durationa slot in a stack frame (or just a register)
static storage durationdata or bss
dynamic storage durationheap memory from the allocator
thread storage durationa per-thread block set up by the runtime
The C++ standard never says "stack" or "heap". It specifies storage durations and lifetimes. Module 2 is about those.
