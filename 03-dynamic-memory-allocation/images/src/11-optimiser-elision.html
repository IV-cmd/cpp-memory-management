A surprise: at -O1 the leak disappeared
Build of leak.cppRSS after 1,000 requestsLeakSanitizer
-g -fsanitize=address (-O0)56,504 KiB40,000,000 bytes leaked
-g -O1 -fsanitize=address6,464 KiBnothing to report
The buffer is written but never read, so the optimiser removed the new and the memset entirely. C++14 allows the compiler to skip allocations like this. Real code that uses its buffers still leaks.
